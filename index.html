        ℹ️ ダイヤグラム運転整理 操作ガイド
        
      

      

        
1. ダイヤグラムのスクロールと操作

        
    
          
  • マウスホイール (上下回転): ダイヤグラムをスムーズに縦スクロール（東京〜下田の全41駅を自由に上下移動）。
    • 
          
  • Shift + マウスホイール / 横ホイール: 時間軸の横スクロール。
    • 
          
  • 画面下端の横スクロールバー: ドラッグして時間帯（08:00〜11:30）を素早く横移動。
    • 
          
  • 画面上部の時間ボタン [◀ 30分] [🔴 現在時刻] [30分 ▶]: ワンクリックで時間横ジャンプ。
    • 
          
  • 画面上部の駅ボタン [東京][横浜][熱海][伊東][下田]: 目的の駅へワンクリックで縦ジャンプ。
    • 
          
  • 画面右端の縦スクロールバー: ドラッグして全区間を一気に移動。
    • 
          
  • キーボード矢印キー (← → ↑ ↓): 画面を上下左右にスムーズスクロール。
    • 
          
  • Ctrl + ホイール / 🔍+ 🔍- ボタン: ダイヤグラムの拡大・縮小ズーム。
    • 
        


        
2. スジ（列車線）のドラッグ＆確定（新仕様）

        
    
          
  • 前倒し禁止: スジを過去方向（早発）へずらすことはできません（0秒以上のみ）。
    • 
          
  • 出発駅以降のみ遅延: カーソルを合わせた線の出発駅以降のみが出発遅延し、それ以前の駅はそのまま維持されます。
    • 
          
  • 最小停車時間30秒＆自動遅延回復: 駅での停車時間は必ず30秒以上確保されます。元々1分や2分停車する予定だった駅では停車時間を30秒に短縮し、自動で遅延が縮小・回復します！
    • 
          
  • ドラッグを離すと画面下に「✓ この変更を確定する」ボタンが出現し、確定を押すとシミュレーションに反映されます。
    • 
        


        
3. 衝突・支障の赤色警告表示

        
    
          
  • 単線区間での駅間正面衝突や、駅間追突・番線重複が予測される場合、ダイヤグラム上のスジと交点が赤色に光り、警告マーカー（🚨）が表示されます。
    • 
          
  • スジをドラッグして交換可能駅で行き違いさせると、危険が解消されて通常色に戻ります。
    • 
        


        
4. 駅交点クリック・配線図・難易度

        
    
          
  • スジ上の駅交点（丸印）をクリックすると、発着時刻の手入力や番線変更、発車抑止(HOLD)が可能です。
    • 
          
  • 左側の「駅名」をクリックすると、その駅の構内配線略図（番線・信号・在線列車）が表示されます。
    • 
          
  • 画面上部の[初級][中級][上級]ボタンで難易度を切り替えられます（上級は実ダイヤ級の超過密運行！）。
    •
