# 運行ダイヤグラム指令盤 - 東海道・伊豆線 (Train Dispatcher Console)

朝〜昼の列車運行を支える「運転指令員」となり、広大な運行ダイヤグラム（スジ引き図）を駆使して、突発遅延や単線区間の交換支障を回避しながらダイヤを回復させるブラウザシミュレーションゲームです。

---

## 🎮 主な特徴 & システム

- **フルスクリーン運行ダイヤグラム（スジ引き盤 & スッキリしたヘッダー）**:
  - 画面上部はごちゃごちゃした余計なボタンを省き、現在時刻・総遅延・スコア・倍速・🔴現在時刻ボタンのみの必要最小限に整理。
  - ダイヤグラム画面が最大化され、広大な運行指令に集中できます。
  - **エンドレス運行（パターンダイヤの無限周期生成）**:
    - 1時間サイクルのパターンダイヤ（特急踊り子、快速アクティー、普通、単線交換便など）が未来へ向かって延々と自動生成され、いつまでもエンドレスに運行調整が楽しめます。
    - 計画ダイヤ（点線スジ）も未来時間へ向かってシームレスに繰り返し描画されます。
  - **マウスホイール (上下回転)**: ★**スムーズな縦スクロール**（東京〜熱海〜伊豆急下田の全41駅を上下に移動）。
  - **Shift + マウスホイール / 横ホイール**: ★**時間軸の横スクロール**。
  - **画面下端の横スクロールバー**: つまみをドラッグして過去〜未来の時間帯を自由に横移動。
  - **画面右端の縦スクロールバー**: つまみをドラッグして全41駅を一気に縦移動。
  - **🔴 現在時刻ボタン**: いつでも現在時刻の位置へ瞬時にカメラをセンタリング。
  - **キーボード矢印キー (← → ↑ ↓)**: 上下左右に自由スクロール。
  - **Ctrl + ホイール / 🔍+ 🔍- ボタン**: 時間軸の拡大・縮小。
- **実在有名路線モデル（全41駅：複線＋単線のハイブリッド）**:
  - **複線区間（東京 〜 熱海：21駅）**:
    - 東京、新橋、品川、川崎、横浜、戸塚、大船、藤沢、辻堂、茅ヶ崎、平塚、大磯、二宮、国府津、鴨宮、小田原、早川、根府川、真鶴、湯河原、熱海
    - 上下線が分離。駅間でのすれ違い自由。待避駅（平塚、国府津、小田原など）で特急・快速が普通列車を追い越し。
  - **単線区間（熱海 〜 伊豆急下田：20駅）**:
    - 来宮、伊豆多賀、網代、宇佐美、伊東、南伊東、川奈、富戸、城ヶ崎海岸、伊豆高原、伊豆大川、伊豆北川、伊豆熱川、片瀬白田、伊豆稲取、今井浜海岸、河津、稲梓、蓮台寺、伊豆急下田
    - **線路が1本のみ**！駅間に対向列車が同時に進入すると正面衝突（閉塞支障インシデント）。必ず駅（交換可能駅）で行き違い（交換待ち）を成立させる必要があります。
- **スジのドラッグ移動 & 確定ボタン**:
  - スジ（列車線）を左右にドラッグすることで、時間を遅らせたり早めたりする変更プレビュー（仮スジ・黄色破線）を生成。
  - ドラッグを離すと画面下に**「✓ この変更を確定する (Enter)」**ボタンが出現。確定を押すまではシミュレーションの運行には反映されず、「✕ 取消 (Esc)」で元に戻せます。
- **スジと駅の交差ノード（丸印）クリック**:
  - スジ上の各駅の交点（丸印）をクリックすると、**到着時刻・出発時刻の直接手入力**や、その駅での**着発番線変更**、**発車抑止(HOLD)**が設定できます。
- **駅構内配線略図ポップアップ**:
  - ダイヤグラム左側の**「駅名」をクリック**すると、その駅の配線略図（ホーム番線、在線列車、信号現示）がポップアップ表示されます。
